# 508 Consulting | Premium Agency Portal

A cinematic, high-performance "Showcase" dashboard designed to demonstrate the power of AI-driven business orchestration. This portal has been meticulously migrated from a legacy React environment to a fully static, standalone HTML5/CSS3/JS architecture to ensure maximum performance, zero external dependencies, and a "perfect" demo experience.

## 🚀 Core Features

### 1. AI Agent Orchestration Hub
- **Dynamic Dashboards**: Each AI agent (Marketing Strategist, Ad Optimizer, etc.) has its own dedicated dashboard.
- **Performance Matrix**: Real-time visualization of agent efficiency using Chart.js.
- **Live Execution Logs**: Simulated autonomous activity streams that showcase the AI's "thinking" process.

### 2. Social Media Cockpit
- **Channel Health**: Real-time monitoring of audience sentiment, response times, and reach growth.
- **Engagement Analytics**: Beautifully rendered charts showing platform growth and top-performing content.
- **Content Scheduler**: An interactive workflow for orchestrating multi-channel brand distribution.

### 3. Smart Inbox (Lead Scout)
- **AI-Scoring**: Automated lead qualification with intent-based status tags (e.g., "High Intent", "Follow-up Needed").
- **Draft-Ready Indicators**: Visual cues showing when the AI has already prepared a response for human review.

### 4. Business Intelligence Reports
- **Revenue Distribution**: Deep-dive line charts tracking business growth over time.
- **Channel Distribution**: Doughnut charts visualizing lead acquisition across SEO, Ads, and Social.
- **Performance Table**: Granular breakdown of individual campaign ROI and conversion rates.

### 5. Premium Design System
- **Cinematic Aesthetics**: A glassmorphic UI with vibrant gradients and smooth micro-animations.
- **Theme Switcher**: Functional Light (Snow White) and Dark (Onyx) modes with persistent storage.
- **Modern Typography**: Powered by Google Fonts (Inter & Outfit).

## 🛠 Technical Architecture
- **Structure**: Pure Semantic HTML5
- **Logic**: Vanilla Javascript (ES6+)
- **Styling**: Modern CSS3 with Custom Properties (Variables)
- **Visualizations**: Chart.js (via CDN)
- **Persistence**: LocalStorage for theme states and user preferences.

## 📂 Project Structure
- `/index.html`: The landing portal.
- `/dashboard.html`: The main overview hub.
- `/dashboard-agents.html`: Dynamic AI Agent dashboards.
- `/dashboard-social.html`: Social Media orchestration.
- `/dashboard-leads.html`: Smart Inbox interface.
- `/dashboard-reports.html`: BI Reporting suite.
- `/dashboard-settings.html`: Comprehensive account management.
- `/style.css`: Global design system and theme tokens.
- `/theme-switcher.js`: Global theme management logic.
- `/ios-app/`: Standalone Xcode project and Swift source files.
